Частые вопросы

Что ещё хочешь знать?

Это подписка?

Нет, разовый платёж. Платите 200₽ один раз — пользуетесь навсегда.

PRO для одного чата или для всех?

Для одного чата. Если создадите новый чат — там будет FREE. Это чтобы каждая компания платила за себя.

Как считаются очки?

Победа в основное время — 2:0. Победа по пенальти — 2:1. Ничья (без пенальти) — 1:1.

Можно ли редактировать результаты?

Да, кнопка «✏️ Редактировать» в активном турнире. Изменения пересчитывают всю статистику.

Бот работает в личке?

Нет. Только в групповых чатах — нужно минимум 2 участника для турнира.

Где хранятся данные?

В облачной базе данных PostgreSQL. Данные не теряются при перезапуске сервера.

Сколько матчей в турнире?

2 участника → 1 матч. 3 → 3. 4 → 6. 5 → 10. Формула: N×(N-1)/2.

Как пригласить друзей?

Просто поделитесь ссылкой на бота. Каждый новый чат получает свои данные (изолированно).
